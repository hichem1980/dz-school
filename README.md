# DZ School

DZ School is a modern educational website focused on Algerian study materials, including homework, exams, summaries, and subject resources in Arabic and French.

## Features
- Arabic and French interface
- Study levels: primary, middle, secondary, and baccalaureate
- Subjects: mathematics, sciences, Arabic, English, history, and more
- Search and subject filtering
- Responsive design for desktop and mobile

## Project structure
- `index.html` — main landing page
- `styles.css` — layout, design, and responsive styling
- `script.js` — data rendering, language toggle, and search/filter logic

## Run locally
Open `index.html` in a browser, or use a simple local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## GitHub Pages
This project can be deployed easily with GitHub Pages from the repository root.
